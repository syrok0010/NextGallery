- [cancel-all.png](cancel-all.png): отмена всей очереди останавливает текущий PUT и пропускает следующий файл. Предыдущая успешная партия остаётся в истории. Серверный HEAD обоих отменённых файлов вернул 404.
- [cancellation.mp4](cancellation.mp4): на финальном APK отмена одного файла закрывает текущий PUT; следующий начинает передачу и останавливается отменой партии. Затем системное уведомление открывает экран загрузок. Видеозапись перекодирована из настоящей записи `agent-device`, без изменения сценария.
- [notification.png](notification.png), [from-notification.png](from-notification.png): итог «Отменено: 2» и результат нажатия на него.

Запуск: один Gradle worker, heap 1 ГБ, компилятор Kotlin в процессе Gradle. Instrumentation только скомпилированы, полного connected-прогона не было. Отмена с добавлением в альбом проверена JVM-контрактом follow-up; отдельный живой альбом в UI не создавался.

Очередь не переживает process death. Совпадение размера при 412 сохраняет утверждённую эвристику #131 и не доказывает равенство содержимого: разные файлы одинакового размера могут быть приняты за одну копию. Отмена не откатывает байты, уже принятые сервером до закрытия соединения.
