# Материалы проверки «Загрузка локальных + добавление в альбом»

Эмулятор API 36 + тестовый Nextcloud/Memories `http://test.syrok/`, сборка `automation` ветки `feat/upload-to-album`.

- `upload-small.mp4` / `upload.gif` — 1 облачный + 2 локальных → «Новый альбом» `NG-upload` → snackbar → уведомление «Загрузка завершена: 2 из 2 · В «NG-upload»: 2».
- `conflict-small.mp4` / `conflict.gif` — 2 локальных файла с именами, уже занятыми в облаке (`412`): совпавший по размеру добавлен, другой — нет.
- PNG — ключевые состояния.

Ветка не предназначена для слияния.
