# NextGallery

NextGallery — развивающаяся Android-галерея для личной медиатеки на телефоне и в Nextcloud Memories.

Сейчас приложение закрывает базовый сценарий единого просмотра локальных и облачных медиа. Это только фундамент: проект развивается в полноценный клиент для управления, синхронизации и удобной навигации по личному фотоархиву.

## Что уже работает

- Единая лента локальных и облачных фото и видео, сгруппированная по дням.
- Объединение совпадающих локальной и облачной копий.
- Полноэкранный просмотр фотографий с масштабированием и жестами.
- Безопасное подключение к Nextcloud с подтверждением входа в браузере.

## Куда развивается проект

- Ручной выбор и загрузка фотографий в облако.
- Удаление облачных и локальных копий, в том числе безопасное освобождение места после загрузки.
- Работа с альбомами, добавление фотографий и удобный общий доступ.
- Автоматическая синхронизация новых фотографий.
- Просмотр медиатеки по карте, лицам и другим полезным признакам.

Подробные планы развития описаны в [текущем состоянии продукта](docs/product/mvp.md).

## Требования

- Android 12 (API 31) или новее.
- Доступный по сети сервер Nextcloud с установленным и настроенным приложением [Memories](https://memories.gallery/).

## Запуск из исходников

1. Откройте проект в Android Studio и дождитесь Gradle Sync.
2. Подключите устройство или запустите эмулятор с Android 12+.
3. Запустите конфигурацию `app`.
4. В приложении укажите URL своего Nextcloud, откройте браузер и подтвердите вход.

## Ограничения

- Поддерживается один подключённый аккаунт Nextcloud/Memories.
- Для показа локальной медиатеки нужен полный доступ к фото и видео на устройстве.
- Видео участвует в ленте, но пока не воспроизводится.
- Сервер без установленного Memories пока не поддерживается.
