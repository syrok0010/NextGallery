# Проверка PR #91 на Android 16

Ревизия приложения: `60bd2b08b754bd94fccdcb453a0862086aa3cdfd`. Стенд: `http://test.syrok/`,
только синтетические фото и видео. Проверено 17 октября 2026 года.

- Панель выбора заменяет нижнюю навигацию; крестик и «Назад» восстанавливают её.
- Первый upload запрашивает уведомления. Выбранный список сохранён до ответа.
- После отказа upload продолжается с предупреждением; повторный upload не спрашивает снова.
- Ролик 254 406 353 байта (243 МиБ) передан при свёрнутом приложении.
  Уведомление показывает передачу и сохраняет результат после остановки сервиса.
- SHA-256 всех шести файлов совпал с исходниками: [sha256.json](sha256.json).
- Повторный PUT получает 412; существующие файлы не перезаписываются.
- При смешанном выборе облачная копия пропускается.
- Сборка automation, Spotless, 187 JVM-тестов, feature boundaries прошли.
- Три instrumentation-теста UploadPermissionFlowTest прошли, включая сохранение
  списка при пересоздании Activity и защиту от повторного ответа.

## Прогресс текущего файла и индикатор выбора

- Счётчик «1 из 2» показывает позицию файла, полоса под ним — долю переданных байтов текущего файла.
- Неизвестный размер показывается неопределённым индикатором. Промежуточные обновления объединяются и публикуются не чаще двух раз в секунду: иначе Android может отбросить итоговое уведомление.
- Выбранный тайл отмечается векторной галочкой в круге с контрастной обводкой.
- JVM: 192 теста без ошибок; пять новых проверяют потоковую передачу, повторную запись тела, ограничение частоты, неизвестный/нулевой/большой размер и ошибку чтения.
- На эмуляторе API 36 переданы два видео по 243 МиБ в живой http://test.syrok/. В `progress-samples.json` записаны значения системного уведомления; SHA-256 обоих файлов сверен с исходниками (`progress-sha256.json`).
- `current-file-progress.mp4` и `current-file-progress.gif` показывают выбор, передачу в фоне, переход ко второму файлу и итоговое уведомление.
