# NextGallery

Native Android-клиент для просмотра личного фотоархива в Nextcloud Memories и локальных медиа на устройстве. Проект развивается как remote-first MVP с единым timeline для доступных источников.

## Что уже работает

- Подключение к Nextcloud через Login Flow v2: авторизация подтверждается в браузере, приложению выдаётся отдельный app password.
- Проверка и загрузка данных из Memories API.
- Timeline с группировкой по дням, ленивой загрузкой деталей и thumbnails по мере прокрутки.
- Локальный warm-start cache: индекс timeline и thumbnails сохраняются между запусками; устаревшие данные инвалидируются при изменении архива.
- Просмотр фото и видео в полноэкранном pager: масштабирование изображения, переход к соседним элементам, свайп вниз и системный predictive back для закрытия.
- Показ локальных фото и видео в общем timeline после предоставления полного доступа к медиатеке.
- Кнопки обновления timeline и выхода из аккаунта. При выходе удаляются сохранённые учётные данные и кэш медиа.

## Требования

- Android 12 (API 31) или новее.
- Доступный по сети сервер Nextcloud с установленным и настроенным приложением [Memories](https://memories.gallery/).
- Android Studio с поддержкой AGP 9.2.1 либо JDK 11 для сборки из командной строки.

## Запуск

1. Откройте проект в Android Studio и дождитесь Gradle Sync.
2. Подключите устройство или запустите эмулятор с Android 12+.
3. Запустите конфигурацию `app`.
4. В приложении укажите URL своего Nextcloud, откройте браузер и подтвердите вход.

Сборка из терминала:

```bash
./gradlew :app:assembleDebug
```

Запуск unit-тестов:

```bash
./gradlew :app:testDebugUnitTest
```

## Технологии

- Kotlin и Jetpack Compose / Material 3;
- Navigation 3, Koin и Kotlin Serialization;
- Retrofit/OkHttp для Nextcloud и Memories API;
- Room и файловый кэш thumbnails;
- Coil 3 и Telephoto для загрузки и масштабирования изображений.

## Ограничения текущего MVP

Приложение рассчитано на один личный аккаунт и сервер с Memories. Локальные медиа доступны только при полном системном разрешении и пока не объединяются с облачными копиями. Не реализованы загрузка и синхронизация файлов, альбомы, избранное, шаринг, удаление и полноценный fallback на обычный WebDAV Nextcloud.
