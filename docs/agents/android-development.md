# Android-разработка

## Сборка APK

Когда нужен APK для ручной проверки опубликованной ветки, предпочитай GitHub Actions
**Test APK** локальной сборке: R8 выполняется на GitHub runner и освобождает ресурсы
нашего хоста для эмулятора и других задач. Порядок запуска и скачивания — в
[тестовых сборках](release.md#тестовые-apk).

Используй CI в рамках уже разрешённого commit/push. Для быстрых проверок
незакоммиченных правок подходят локальные целевые тесты и компиляция. Если проверка
текущего SHA уже прошла в CI, повторяй её локально только при отдельной необходимости.
Перед установкой APK сверь `headSha` успешного запуска с проверяемым commit и проверь
`SHA256SUMS`. Запуск сборки и скачивание файла ещё не подтверждают проверку приложения.

## Устройство

По умолчанию используй эмулятор на `syrok-server` через T3 Code: локальный device
host на сервере, SSH device host `syrok-server` на `syrok-arch`. Всё, что делает
пользователь — запуск, нажатия, ввод, разрешения, скриншоты, запись, — идёт через
`device_*` и `agent-device`, чтобы пользователь видел это в Device panel. `adb`
остаётся для того, чего `agent-device` не умеет: сборка и установка, логи, файлы
и MediaStore (`push`, `MEDIA_SCANNER_SCAN_FILE`, `content query`), язык приложения.

Реальный телефон используй только по явному указанию пользователя с выбранным
ADB serial. Команды тестирования и защита данных телефона — в [testing.md](testing.md).
