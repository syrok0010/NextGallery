# Android-разработка

По умолчанию используйте `nextgallery-api36-dev` на `syrok-server` через T3 Code:
локальный device host на `syrok-server`, SSH device host `syrok-server` на
`syrok-arch`. Управляйте устройством через `device_*` и `agent-device`.

Реальный телефон используйте только по явному указанию пользователя с выбранным
ADB serial. Недоступность эмулятора не разрешает автоматически перейти на телефон.

Dev-AVD сохраняет рабочие данные. Для финальной runtime-проверки используйте
`nextgallery-api36-smoke`; сбрасывайте данные только этого устройства, когда
сценарию нужно чистое состояние. На сервере запускайте один AVD за раз.
Выключайте запущенный вами AVD после проверки, если пользователь не попросил
оставить его работающим.

На `syrok-arch` Device Hub даёт доступ к удалённому экрану и управлению, но не
к локальному ADB: APK должен быть доступен на хосте команды установки.
Для сборки и instrumentation следуйте [правилам тестирования](testing.md).

Артефакты проверки сохраняйте в `build/android-dev/` или `build/android-smoke/`.
