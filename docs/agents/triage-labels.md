# Triage labels

Проект пока использует минимальный label vocabulary.

## Основные labels

- `ready-for-agent` - задача достаточно описана, агент может брать ее без дополнительного контекста.
- `needs-decision` - нужно решение автора проекта или обсуждение trade-offs.

## Существующие GitHub labels

- `bug` - дефект.
- `enhancement` - новая возможность или улучшение.
- `documentation` - документация.
- `question` - исследовательская задача или открытый вопрос.
- `help wanted` - нужна человеческая помощь или внешний вклад.
- `wontfix` - не планируется к выполнению.

## Правило

Не добавлять area-labels заранее. Если issues станет много и фильтрации перестанет хватать, можно отдельно ввести labels вроде `area: auth`, `area: timeline`, `area: sync`.
