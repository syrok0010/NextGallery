# ADR 0021: Английский и русский языки приложения

## Статус

Принято по [#103](https://github.com/syrok0010/NextGallery/issues/103) и
[#148](https://github.com/syrok0010/NextGallery/issues/148).

## Контекст

Строки лежали только в `values/` на русском, а plurals и названия месяцев Android
выбирает по языку конфигурации. На английской системе получалось «2 элементов» и
«31 October». Часть строк была английской, то есть язык по умолчанию не был выбран.

## Критерии выбора

- Формы plurals и даты совпадают с языком показанных строк на любой системе.
- Пользователь выбирает язык средствами Android, без своего экрана настроек.
- Нет своего кода выбора языка на старте и подмены конфигурации.

## Решение

Английский — язык по умолчанию в `values/`, русский — в `values-ru/`. `localeConfig`
объявляет `en` и `ru`, поэтому на Android 13+ язык приложения выбирается в системных
настройках. Android берёт ресурсы и правила plurals по одной конфигурации, поэтому
русские строки показываются только с русскими правилами.

Шаблоны дат лежат в ресурсах вместе со строками. Названия месяцев и дней недели
берутся из `language_tag` ресурсов (`rememberDateFormatter`), а не из системы: на
неподдерживаемом языке системы строки и даты откатываются к английскому вместе.

Instrumented-тесты ищут текст через ресурсы и не зависят от языка устройства.

## Альтернативы

- **Только русский с принудительной локалью** (PR #149): `LocaleManager` при первом
  запуске и подмена ресурсов Application и Activity на Android 12. Больше кода на
  старте ради одного языка, а английского интерфейса нет.
- **Русский в `values/`, английский в `values-en/`.** Неподдерживаемые языки
  системы получили бы русский интерфейс.

## Последствия

На английской системе приложение по умолчанию английское; русский выбирается в
«Язык приложения» (Android 13+). На Android 12 язык приложения следует системе.
На неподдерживаемом языке системы английские plurals подбираются по правилам этого
языка: формы, которых нет в английском, берут `other`.

## Открытые вопросы

- Названия качества видео («Auto», «Original») приходят из кода, а не из ресурсов
  ([#187](https://github.com/syrok0010/NextGallery/issues/187)).
