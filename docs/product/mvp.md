# Текущее состояние и этапы продукта

## Реализованная основа

NextGallery уже проходит основной single-account сценарий:

```text
Login Flow v2 -> Memories API -> unified timeline -> viewer -> warm-start cache
```

Приложение:

- сохраняет единственную авторизованную сессию в Android Keystore;
- загружает Memories timeline и remote thumbnails;
- индексирует доступные локальные фото и видео из MediaStore;
- показывает каталог серверных альбомов и локальных папок, открывает их содержимое и листает медиа внутри выбранного альбома;
- добавляет выбранные в таймлайне медиа в свой альбом Nextcloud или в новый альбом; локальные объекты без облачной копии сначала загружаются в облако;
- сохраняет принятую загрузку отдельно от последующего link/album-действия и даёт явно повторить такое действие без новой передачи;
- удаляет выбранные в таймлайне медиа в корзину Android и корзину Nextcloud; для объектов с обеими копиями спрашивает, откуда удалять;
- объединяет локальные и облачные копии по устойчивому `MediaId` и приблизительным `AUID`/`BUID`; загруженный из приложения файл связывается со своей облачной копией по `fileId` из ответа сервера;
- показывает cached local projection и материализованную cloud metadata до завершения refresh;
- воспроизводит локальные и облачные video originals в detail view после явного запуска; при ошибке локальной копии переключается на Memories original в той же playback session;
- раскрывает локальное и облачное видео в ленту кадров с перемоткой внутри текущего медиаобъекта;
- использует Memories HLS при несовместимости remote original и позволяет выбрать доступное серверное качество с сохранением позиции и play/pause intent.

Подробные требования и незавершённые части ведутся в GitHub Issues, а устойчивые технические решения — в `docs/adr/`.

## Продуктовые границы

- Nextcloud/Memories-авторизация обязательна даже для показа локальной библиотеки.
- Приложение однопользовательское. Выход удаляет все данные приложения; другой аккаунт можно подключить только как после свежей установки.
- Android partial photo access пока не считается полной локальной библиотекой.
- Warm-start cache не является полноценным offline mode.
- Миграции Room и совместимость локального dev-состояния пока не гарантируются; destructive reset допустим, в том числе для журнала ручных загрузок ([ADR 0019](../adr/0019-durable-manual-uploads.md)).

## Планируемые направления

Порядок направлений не зафиксирован.

### Управление медиатекой

- ручные задания выполняет WorkManager по журналу, с автоматическим повтором временных сбоев; пользовательские политики загрузки (сеть, зарядка) остаются следующим срезом;
- безопасное освобождение места на устройстве для медиа с подтверждённой cloud copy.

### Альбомы и sharing

- добавление в shared-альбомы;
- удобный UI для sharing альбомов и фото.

### Автосинхронизация

- upload и download/offline queues;
- background work через WorkManager;
- retry/backoff и политика конфликтов;
- ограничения по сети и зарядке;
- более сильная связь локальной и облачной копий, загруженных не из NextGallery, чем приблизительные `AUID`/`BUID`.

### Discovery

- просмотр по карте;
- группировка и поиск по лицам;
- другие полезные представления, уже проверенные Memories Web, Immich и похожими фотопродуктами.

## Вне текущего scope

- несколько аккаунтов и account switcher;
- полноценная работа с Android Selected Photos Access;
- гарантированный полный offline archive;
- WebDAV fallback без подтверждённого пробела Memories API.
