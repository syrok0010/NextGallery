# MVP

## Направление MVP-1

Первый MVP: remote-first клиент для Memories/Nextcloud.

Минимальный полезный сценарий:

1. Пользователь указывает адрес своего Nextcloud.
2. Приложение проходит Nextcloud Login Flow v2 и получает app password.
3. Приложение проверяет доступность Memories API.
4. Приложение загружает удаленный timeline.
5. Пользователь видит сетку фото/видео.
6. Пользователь открывает элемент и видит preview/original-версию.
7. Приложение кеширует базовые метаданные и thumbnails.

## Почему не sync-first

Синхронизация - один из самых сложных блоков продукта:

- фоновые ограничения Android;
- конфликты между локальным и удаленным состоянием;
- дубли;
- удаление и восстановление;
- сетевые ошибки;
- квоты и ограничения сервера;
- энергопотребление.

Если начать с полной синхронизации, легко потратить много времени до появления видимого результата. Remote-first MVP быстрее проверяет главный риск: можно ли построить приятный native UX поверх Memories/Nextcloud.

## Почему не local-first

Локальная галерея через Android MediaStore важна, но она не проверяет уникальную ценность проекта. Хороших локальных галерей уже много. Отличие NextGallery - интеграция с личным Nextcloud/Memories архивом.

## Обязательные возможности MVP-1

- Подключение аккаунта через Nextcloud Login Flow v2.
- Сохранение учетных данных безопасным способом.
- Проверка `/apps/memories/api/describe`.
- Загрузка списка дней через Memories `/apps/memories/api/days`.
- Загрузка фото конкретного дня через `/apps/memories/api/days/{id}`.
- Отображение timeline/grid в Compose.
- Загрузка thumbnails через Memories image preview API.
- Экран detail для одного `MediaItem`.
- Базовый локальный кеш метаданных.
- Обработка пустого состояния, ошибки авторизации и недоступности Memories.

## Не цели MVP-1

- Автоматическая загрузка локальных фото на сервер.
- Двусторонняя синхронизация.
- Редактирование EXIF.
- Создание альбомов.
- Удаление файлов.
- Шаринг.
- People/places/tags.
- Video transcoding UX.
- Поддержка нескольких аккаунтов.

## MVP-2: локальные фото

После remote-first вертикали добавить `LocalMediaSource` поверх Android MediaStore:

- запрос runtime permissions;
- чтение локальных фото и видео;
- единая доменная модель с remote media;
- признак "есть локальная копия" / "есть remote-копия";
- первый вариант unified timeline.

## MVP-3: синхронизация

После появления remote и local источников можно проектировать sync engine:

- upload queue;
- download/offline queue;
- background work через WorkManager;
- политика конфликтов;
- retry/backoff;
- пользовательские состояния "только Wi-Fi", "только зарядка", "не синхронизировать эту папку".

## Tracer bullet

Первый кодовый tracer bullet:

```text
Login -> describe API -> days -> day photos -> grid -> detail -> thumbnail cache
```

Этот путь должен заработать на Galaxy S24 Ultra и личном Nextcloud до расширения продукта.
