# Текущее состояние и этапы продукта

## Реализованная основа

NextGallery уже проходит основной single-account сценарий:

```text
Login Flow v2 -> Memories API -> unified timeline -> viewer -> warm-start cache
```

Приложение:

- сохраняет единственную авторизованную сессию (Login Flow v2) в Android Keystore и проверяет наличие Memories 11+; выход полностью очищает данные приложения и блокируется при активных операциях;
- загружает Memories timeline и remote thumbnails, индексирует доступные локальные фото и видео из MediaStore;
- объединяет локальные и облачные копии по устойчивому `MediaId` и приблизительным `AUID`/`BUID`; загруженный из приложения файл связывается со своей облачной копией по `fileId` из ответа сервера;
- показывает cached local projection и материализованную cloud metadata до завершения refresh (warm-start cache);
- воспроизводит локальные и облачные video originals в просмотрщике после явного запуска (при ошибке локальной копии переключается на Memories original в той же playback session), раскрывает видео в ленту кадров с перемоткой и использует Memories HLS с выбором доступного качества при несовместимости remote original;
- показывает каталог серверных альбомов и локальных папок, открывает их содержимое и листает медиа внутри выбранного альбома;
- выполняет ручную загрузку локальных фото и видео в облако из ленты (включая мультивыделение) и из просмотрщика: фоновая очередь в WorkManager по журналу (`upload-journal.db`), разбиение крупных файлов на чанки, автоматический повтор временных сбоев, экран статуса загрузок с отменой и ручным повтором;
- добавляет медиа из ленты и просмотрщика в свой существующий или новый альбом Nextcloud; локальные объекты без облачной копии сначала загружаются в облако, при этом принятая загрузка сохраняется отдельно от последующего link/album-действия с возможностью повторить только это действие без новой передачи;
- удаляет выбранные медиа из ленты и просмотрщика в корзину Android и корзину Nextcloud (после проверки доступности корзины на сервере); для объектов с обеими копиями спрашивает, откуда удалять;
- поддерживает английский и русский языки интерфейса через системные настройки Android.

Подробные требования и незавершённые части ведутся в GitHub Issues, а устойчивые технические решения — в `docs/adr/`.

## Продуктовые границы

- Базовые продуктовые инварианты (single-account, обязательная авторизация, полная очистка при выходе, отсутствие гарантий обратной совместимости на раннем этапе) зафиксированы в [видении проекта](vision.md#продуктовые-границы).
- Android Selected Photos Access (частичный доступ) пока не поддерживается как полная локальная библиотека.
- Warm-start cache не является полноценным offline mode.
- Действия над медиа (загрузка, добавление в альбом, удаление) пока доступны из общей ленты и её просмотрщика, но не из экрана конкретного альбома.
- Миграции Room и совместимость локального dev-состояния пока не гарантируются; destructive reset допустим, в том числе для журнала ручных загрузок ([ADR 0019](../adr/0019-durable-manual-uploads.md)).

## Планируемые направления

Порядок направлений не зафиксирован.

### Управление медиатекой

- действия над медиа из экрана альбома;
- пользовательские политики загрузки (ограничения по сети и зарядке);
- безопасное освобождение места на устройстве для медиа с подтверждённой cloud copy;
- избранное и другие действия с метаданными.

### Альбомы и sharing

- добавление в shared-альбомы;
- удобный UI для sharing альбомов и фото.

### Автосинхронизация

- автоматическая фоновая загрузка новых локальных фото и видео, а также offline/download-очереди;
- retry/backoff, ограничения по сети и зарядке и политика конфликтов;
- более сильная связь локальной и облачной копий, загруженных не из NextGallery, чем приблизительные `AUID`/`BUID`.

### Discovery

- просмотр по карте;
- группировка и поиск по лицам;
- другие полезные представления, уже проверенные Memories Web, Immich и похожими фотопродуктами.

## Вне текущего scope

- несколько аккаунтов и account switcher;
- полноценная работа с Android Selected Photos Access;
- гарантированный полный offline archive;
- WebDAV fallback без подтверждённого пробела Memories API.
